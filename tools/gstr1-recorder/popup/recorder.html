📼 GSTR-1 Recorder

Captures DOM, ng-click structure, scope flags & API calls on gst.gov.in

How to record the 3 scenarios
  1. Load this extension: chrome://extensions → Developer mode → Load unpacked → select the gstr1-recorder folder.
  2. Open gst.gov.in, log in, and reload the tab so the recorder attaches.
  3. Pick the scenario above, then click 📸 on every page state as you walk the flow.
  4. Old format: GSTR-1 → a period before Nov 2021 (e.g. 042021) → capture the landing page, then whatever the portal shows (error page / download button).
  5. New filed: a recent period (e.g. 032022) → capture landing page → click View Summary → capture summary page → click Download Summary (PDF) → capture once more.
  6. New NIL: a NIL-filed recent period → capture landing page + after clicking Download Filed (PDF).
  7. If you hit a Request Rejected or system-error page, capture it too — that's exactly what we need.
  8. When done: ⏬ Export JSON and send the downloaded .json file back (one file per scenario is ideal).
